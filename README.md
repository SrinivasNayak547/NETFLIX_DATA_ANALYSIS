🎬 Netflix Data Analysis Using Python

📌 Project Overview

This project focuses on analyzing Netflix Movies and TV Shows data using Python. The main objective is to explore the Netflix dataset, identify content trends, understand audience categories, and generate meaningful insights through Exploratory Data Analysis (EDA) and data visualization.

🛠️ Tools & Technologies

- Python – Programming language
- Pandas – Data cleaning and manipulation
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization
- Jupyter Notebook – Development environment

📂 Dataset Information

The project uses the Netflix Movies and TV Shows dataset ("netflix_titles.csv").

The dataset contains information about:

- Show ID
- Type (Movie / TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

🔍 Project Activities

1. Imported the Netflix dataset using Pandas.

▶️ How to Run This Project

1. Clone or download this repository.
2. Install the required Python libraries:

pip install pandas numpy matplotlib seaborn jupyter

3. Open Jupyter Notebook:

jupyter notebook

4. Open "NETFLIX DATA ANALYSIS.ipynb".
5. Make sure "netflix_titles.csv" is in the correct folder.
6. Run the notebook cells to explore the analysis and visualizations.
